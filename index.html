这是一个 占位页面。真正的功能从 Day 7 开始往里填 —— 在那之前，所有页面改动都是为「让老师知道项目在动」服务的。

占位页不是"不重要的页面"。它的作用是第一个 commit 的证据： 只要这个文件能出现在 GitHub 仓库里，就说明你的 Git 4 步跑通了。

今日所学（Day 2）

  • Git 4 步：写文件 → git add → git commit → git push
  • .gitignore 黑名单：名单里的文件永远不进 GitHub（今天保证 .env 已在名单上）
  • 第一次 commit 的水印格式：Day 2｜一句话
  • Git（电脑里的总账）和 GitHub（云端网页相册）的分工
