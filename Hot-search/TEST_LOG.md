## 三、本次修复（板块③：只改这一处）

**修复对象：卡点 1（印章压标题）—— 只看这一个，不顺手改别的。**

### 根因

两条 CSS 打架：

```css
.header-seal { position: absolute; top: 28px; right: 32px; }  /* 本该在右上角 */
.site-header > *:not(.header-ink) { position: relative; }     /* Day 11 加的 */
```

第二条的选择器**把印章也算进去了**，且它的特异性（0,2,0）高于第一条（0,1,0），
于是印章的 `absolute` 被改成 `relative`，从右上角**掉回文字流**，压在标题左上角。

### 为什么之前一直没发现（今天要掌握的那个问题）

- 这条规则是 **Day 11** 为了让文字浮到墨团之上加的，坑在那时就埋下了
- 之后 Day 11–13 我截了十几张图，**每张都看过**，但注意力全在"新做的功能"（墨团晕染、按钮反馈、多页跳转）上
- **老部分被我当成了"已经没问题的背景"** —— 这就是作者视角的盲区：
  **改完 A 之后，眼睛只会去看 A，不会再检查被 A 波及的 B**

### 修法（最小改动）

```css
.site-header > *:not(.header-ink):not(.header-seal) { position: relative; }
```

把印章从那条规则里排除掉，让它自己的 `absolute` 生效；另补 `z-index: 2`（原先靠那条规则顺带获得，现在要自己声明）。

### 修复前后对照

| 修复前 | 修复后 |
|---|---|
| 印章压在标题左上角，"热"字被盖 | 印章回到题头右上角，标题完整 |
